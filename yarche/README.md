# «Ярче» — 60-секундный анимационный шорт

Короткая история в пяти главах — по формату референса («начало отношений → … → сейчас»):
он рисовал её на кофейных стаканчиках, она влюбилась в его краски — и сама попросила его рисовать серым.
Мир теряет насыщенность глава за главой (112% → 14%). Последним гаснет розовый рисунок на стаканчике.

**Формат:** 1920×1080, 60 fps, 60.0 с, H.264 + AAC 320k.

## Что внутри

| Слой | Как сделано |
|---|---|
| Персонажи | Векторные риги в SVG (`src/rig`): глаза с веками и взглядом, брови, рот с фонемной формой, моргание, дыхание, микродвижения головы, 18 пресетов эмоций с плавным смешиванием. |
| Липсинк | `tools/vo_analyze.py` строит огибающую каждой реплики с частотой 60 кадров/с, рот открывается по реальному голосу. |
| Голоса | ElevenLabs v4 (через Higgsfield): Лиза — Elena, Марк — Alexey. Эмоции заданы аудиотегами (`[laughs]`, `[whispers]`, `[sighs]`…). |
| Окружения | Набережная Петербурга (купол, шпиль, пастельные фасады, осенние деревья, река), мастерская под дождём, кухня с кобальтовой плиткой, серый офис, ночная кухня. |
| Камера | 2.5D: слои с параллаксом, глубина резкости, ручная «тряска», плавные наезды (`src/lib/camera.tsx`, `src/lib/shots.ts`). |
| Моушн-графика | Каллиграфический титр с всплеском краски, рисунок маркером в реальном времени, главы с побуквенной анимацией, субтитры по словам, таймлайн-HUD с «выцветающими» чипами, переходы: мазок кисти, всплеск краски, whip-pan с направленным размытием, «жалюзи», затемнение ящиком. |
| Звук | `tools/sound.py`: синтез фоли и атмосфер (город, чайки, колокол, вода, дождь, гром, шаги, уведомления, вибрация, рингтон, клавиатура, часы, ящик стола, сердцебиение), процедурная партитура (фортепиано, музыкальная шкатулка, пэд), реверберация по помещениям, телефонный фильтр, дакинг музыки под голос, компрессия и лимитер. |

## Сборка

```bash
npm install
python3 tools/vo_analyze.py          # огибающие для липсинка
python3 tools/sound.py               # звук → public/audio/mix.wav
npx remotion render Main out/yarche_1080p60.mp4 --crf=16
npx remotion still CardLisa out/cards/CardLisa.png   # карточки персонажей
npx remotion still CardMark out/cards/CardMark.png
npx remotion still StyleBible out/cards/StyleBible.png
```

Голосовые файлы скачиваются скриптом `audio_src/fetch_vo.sh` (ссылки в `audio_src/vo_manifest.tsv`).

Монтажный лист (тайминги глав, реплик, субтитров) — `src/lib/timeline.ts`.
