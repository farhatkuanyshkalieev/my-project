# Шаблон видеоотзыва (сценарий 6)

`testimonial-template.mp4` показывает раскладку ролика. На серых экранах с пунктиром
будет видео клиентки. Это не отзыв, а схема монтажа.

## Структура (30 сек + заставка)

| Сек | Что | Файл‑оверлей |
|---|---|---|
| 0–2,5 | Хук: самая эмоциональная фраза клиентки | `hook-quote.png` (поверх видео) |
| 2,5–4 | Заставка «Я пыталась худеть сама…» | — |
| 4–5,5 | Вопрос 1: «Что вы пробовали до центра?» | `question-1.png` |
| 5,5–11,5 | Ответ 1 + плашка с именем | `lower-third-name.png`, `subtitle-bar.png` |
| 11,5–13 | Вопрос 2: «Что было на первом визите?» | `question-2.png` |
| 13–19 | Ответ 2 | `subtitle-bar.png` |
| 19–20,5 | Вопрос 3: «Что изменилось через месяц?» | `question-3.png` |
| 20,5–26,5 | Ответ 3 | `subtitle-bar.png` |
| 26,5–30 | Призыв «Хотите так же?» | `cta-card.png` |
| 30–32 | Заставка «made by @frht.work» | `python3 tools/add_outro.py` |

## Как снимать

- Вертикально 9:16, 1080×1920. Телефон на уровне глаз, лицо в верхней трети кадра.
- Свет из окна сбоку или спереди, петличный микрофон.
- Клиентка отвечает полными фразами, вопрос в ответе повторяет («До центра я пробовала…»).
- Снять 2–3 дубля каждого ответа, потом выбрать самую сильную фразу на хук.
- Текст субтитров заменить на реальные слова клиентки.

## Обязательно

- Письменное согласие клиентки на использование видео в рекламе.
- Только реальная клиентка и её реальные слова и результаты. Не дописывать и не преувеличивать.
- Для таргета Meta: без фото «до/после» в кадре.
