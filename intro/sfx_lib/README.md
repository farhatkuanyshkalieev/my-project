# Библиотека звуков заказчика

Источник: Google Drive, папка «звуки / Саунд Етап» (ссылка от заказчика). В `raw/` только файлы, которые стоят в интро v4.
Куда какой звук ставится, описано в `intro/v4/tools/sound.py` (раздел «user sound library») и в `intro/v4/assets/audio/cues.json`.
`analysis.json` — длительность, начало и пик каждого файла. По ним звуки выравниваются по событиям.
