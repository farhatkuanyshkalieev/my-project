# THERMINAL · INTRO v2

Вступление 9:16, 1080×1920, 60 к/с, 6,6 с. Объект: дверь VIKING 90 «вклейка», реальное сечение с therminal.kz.
Основной ролик не монтировался.

## Как устроено

**Один таймлайн.** `timeline.json` хранит все тайминги, позиции камеры, подписи, размеры, выноски и параметры звука. Его читают прототип (`build.py` вшивает его в страницу), синтез звука и рендер. В прототипе есть панель «Тайминги»: правка сразу меняет анимацию, кнопка копирует обновлённый JSON.

**Сцена 1, 0–3,31 с.** `src/profile3d.js` (three.js r128). Контуры материала получены из чертежа (`tools/solid_from_drawing.py`: стенки, камеры и зазор разделены по толщине областей), затем выдавлены вдоль профиля. Контур не меняется, длина отрезка выбрана для кадра. Покрытие: антрацит со структурой (`src/look.json`), торец — светлый алюминий, на нём линии стыков из того же чертежа. Свет: софтбоксы в карте окружения, контровой свет, бегущая световая полоса (64 шага окружения), тени. Поверх: лёгкое свечение, зерно, виньетка.

**Переход, 3,0–3,5 с.** Камера ускоряется к торцу, размытие до 7 px, экспозиция растёт до ×5, свечение растёт из торца, белый закрывает кадр к 3,31 с.

**Сцена 2, 3,31–6,6 с.** Серый силуэт сечения, затем прорисовка: обводы, камеры, детали с постоянной скоростью пера; чертёж садится в масштаб с 1,07 до 1. Размеры: выносные линии, размерная линия от центра к краям, засечки, подпись. Значения пустые («— мм») до получения чертежа. Выноски: точка с кольцом, линия с изломом, подпись. Табличка, штамп, знак THERMINAL. Ключевые элементы стоят выше нижних 22% кадра, где в Reels лежит интерфейс.

**Звук.** `tools/sound.py` синтезирует эффекты без сэмплов и без голоса:

1. `01_low` — мягкий низкий удар 64→38 Гц в начале и тёмный фон под первой сценой.
2. `02_text` — щелчок с коротким тоном на каждую подпись (тон растёт от слова к слову), тише на малой подписи и табличке.
3. `03_arrow` — шорох пера с полосовым фильтром 1,1→4,2 кГц и панорамой слева направо.
4. `04_transition` — подъём шума, свист наезда, воздушный удар с хвостом реверберации и обратная волна перед ним.
5. `05_drawing` — фактура пера по бумаге на прорисовке, щелчки засечек размеров, мягкие щелчки выносок и штампа.
6. `06_logo` — тёплый колокольный аккорд A4 + E5 с низким тоном и реверберацией.

Общий уровень −20 LUFS, истинный пик около −3 dBFS. Запас нужен, чтобы голос заказчика из исходного видео лёг сверху.

## Пересборка

```bash
python3 build.py
```

```bash
python3 tools/sound.py
```

```bash
node tools/render.js video
```

Другие режимы рендера: `check` (контрольные кадры каждые 0,2 с в `exports/qa/`), `frames` (кадры раскадровки), `layers`, `graphics`. Нужны Chromium с Playwright и ffmpeg. Рендер идёт в 4 процесса; на программном WebGL кадр первой сцены считается около 4 с.

## Ограничения

- Размеры не заполнены: нужен DXF/DWG сечения с размерами.
- Полиамидные вставки и уплотнители на чертеже не выделены, поэтому в 3D у них нет своего материала. Выноска «изоляционная зона» ждёт подтверждения технолога.
- Цвет покрытия подобран по рендерам сайта, код RAL не подтверждён.
- Знак растровый, вырезан из изображения на сайте. Нужен вектор.
- Длина 3D-отрезка выбрана для кадра и не является размером изделия.
