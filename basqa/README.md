# BASQA: рилс для @basqawear

Файл `basqa_reel.mp4`: 8 с, вертикальный 1080×1920 (Instagram Reels / TikTok), 60 fps, H.264 + AAC.

## Откуда взят стиль

Instagram без входа закрыт, поэтому стиль снят с сайта basqa.kz, TikTok, Threads и Pinterest бренда:

- **Цвета:** чёрный `#080808`, белый, один оранжевый `#FE572A` (цвет сайта). Жёлтый `#F5C400` только на бирке.
- **Логотип:** собственный широкий вордмарк BASQA из SVG сайта. В ролике он выдавлен в 3D.
- **Шрифты:** Inter Tight (шрифт сайта), Anton (узкий плакатный, как принт ZAMAN), JetBrains Mono (технические подписи).
- **Мир бренда:**
  - Алматы: горы Алатау, Кок-Тобе, панельные дома;
  - «basqa» по-казахски значит «другой», отсюда слоган ANOTHER VISION;
  - названия дропов: Basqa Qala, Basqa Alem, Zaman;
  - казахский орнамент «қошқар мүйіз»;
  - стикеры и бирки, плёночное зерно, студийные лукбуки с футболкой на вешалке.

## Раскадровка (120 BPM, доля = 0.5 с)

| Время | Кадр | Звук |
|---|---|---|
| 0.0–1.0 | Две струны домбры на чёрном. Их дёргают по рифу, потом натягивают и рвут. Подпись «basqa (каз.) — другой, иной». | Домбра соло, винил |
| 1.0 | **QALA**: «другой город», линия Алматы (горы, Кок-Тобе, панельки, восходящее солнце). | Удар, бочка и аккорд домбры |
| 1.5 | **ALEM**: «другой мир», каркасный глобус, Алматы отмечен точкой. | Удар выше, свист |
| 2.0 | **ZAMAN**: «другое время», циферблат и таймкод самого ролика. | Удар, тиканье, подъём |
| 2.5 | Вордмарк заикается по 16-м долям: белый, чёрный, оранжевый, чёрный. Отсчёт 3-2-1-GO. | Дробь малого, райзер |
| 2.94 | Полная тишина. | Тишина |
| 3.0 | **Дроп.** Оранжевое поле, бегущие строки, орнамент. 3D-логотип падает в кадр с ударной волной. На доли шлёпаются стикеры: ANOTHER VISION, круглый значок с орнаментом, жёлтая бирка LIMITED. | 808 и хлопок на третьей доле, хэты с триольными россыпями, риф домбры сверху |
| 5.0 | Свип в студию. Буквы DROP буквально падают. Футболка BASQA на вешалке падает на штангу ровно на долю и качается в 3D. На 6.0 штамп LIMITED. | Падения, звон вешалки, удар штампа |
| 6.25 | Камера ныряет в принт на спине футболки. | Свист, обратная тарелка |
| 6.5–8.0 | Финал: белый 3D-логотип с оранжевыми гранями, ANOTHER VISION, `@basqawear`, `basqa.kz`, орнамент. | Финальный удар, звенящий аккорд домбры, лик-подпись |

## Сборка

```bash
./build_reel.sh   # node + playwright (chromium), python3 + numpy/scipy, ffmpeg
```

- `basqa.html`, `basqa.js`: сцена. Это 2D-canvas плюс three.js; каждый кадр — функция времени `t`.
- `score_basqa.py`: музыка и звуки, синтез без сэмплов. Читает `build/events.json`.
- `render.js`: Playwright → PNG → ffmpeg; режимы `stills`, `segment`, `events`.
- `assets/basqa_logo.svg`: логотип бренда; `fonts/`: шрифты Google Fonts (OFL).
