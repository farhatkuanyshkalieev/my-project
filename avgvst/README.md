# august (@avgvst.kz): моушн-клип «QYZYL JIP / Красная нить»

Файлы:
- `august_reel.mp4`: 18 с, вертикальный 1080×1920, 60 fps, H.264 + AAC, с треком;
- `august_reel_no_music.mp4`: та же картинка, только звуки. В неё можно поставить лицензированный трек из Instagram: монтаж стоит на сетке 120 BPM.

Сценарий с идеей лежит в [`SCENARIO.md`](SCENARIO.md).

## Что изучено

Instagram без входа закрыт, поэтому материал взят из открытых источников:

- **Профиль бренда:** «august», около 3 400 подписчиков. Био: «Qazaq identical clothing made by @sa1ita [almaty] · order worldwide». В TikTok подпись «qazaq wear». Логотип — строчное «august» тёмно-коричневой антиквой на бежевом (векторизован с аватара).
- **Основательница:** Салтанат (@sa1ita), Алматы. Шьёт сама, заказы принимает со всего мира.
- **Harper's Bazaar Kazakhstan:** «участник Kazakhstan Fashion Week; национальные мотивы проходят сквозь новаторские и утилитарные луки **тонкой красной нитью**; вдохновение в природе и истории Казахстана через деконструкцию, асимметрию и унисекс».
- **WE Project:** «казахстанский бренд в этническом стиле: жилетки, кепки, двойки, пиджаки с национальными орнаментами».
- **Их съёмка (детальный кадр).** Деним с люрексом, рваный край, корсет с бронзовыми пластинами «қошқар мүйіз», кольца вместо пуговиц.

Не путать с ювелирным брендом Avgvst Натальи Брянцевой (Екатеринбург): это другая компания.

## Решения

- **Героиня — красная нить.** Это их собственная формула из Harper's Bazaar. Нить проходит весь путь:
  1. степь, Алатау, солнце;
  2. петроглиф Тамгалы;
  3. рог архара, который становится «қошқар мүйіз»;
  4. сшитый жилет;
  5. двойка;
  6. два силуэта;
  7. настоящее фото;
  8. Алматы и весь мир;
  9. логотип.
- **2D:** линия, петроглифы (точечная «выбивка»), орнамент, типографика. Шрифты: антиква Fraunces, близкая к логотипу, и широкий Unbounded для подписей. Слова на казахской латинице, как пишет сам бренд: *qyzyl jip*, *tarih*, *eki*.
- **3D только для вещей:**
  - детали жилета из индиго-денима с люрексом и рваным краем, асимметричная правая полочка;
  - бронзовые пластины с рельефом «қошқар мүйіз» и петельками;
  - кольца, красная шнуровка, зигзаг на плечах;
  - брюки двойки.
- **Переход к настоящей вещи — склейка по совпадению.** 3D-пластина слетает с жилета и садится точно на место настоящей бронзовой пластины в их кадре. Её ромб раскрывается окном в фото, фото плавно отъезжает от пластины. Подпись: «designed by @sa1ita · almaty».
- **Финал:** крупный логотип august держится около 2.5 с, под ним «qazaq wear», внизу подпись автора «made by @f4rh4t._».
- **Звук:** этно-хаус на 120 BPM в ре миноре.
  - Хук — домбра в технике «қағыс». Кроме неё: кобыз, горловое пение кёмей, бубен-даулпаз.
  - Дроп на ударе бронзовой пластины.
  - У каждого стежка, кольца и пластины свой звук.
  - Всё синтезировано кодом, без сэмплов.

## Сборка

```bash
npm install          # three.js 0.160
./build_reel.sh      # node + playwright (chromium), python3 + numpy/scipy, ffmpeg
```

- `avgvst.html`, `avgvst.js`: сцена (2D-canvas и three.js; каждый кадр — функция времени `t`).
- `score_avgvst.py`: трек и звуки, читает `build/events.json`. Третьим аргументом пишет версию без музыки.
- `assets/august_logo.svg`: логотип, векторизован с аватара.
- `img/august_detail.jpg`: их детальный кадр (через Harper's Bazaar KZ).
- `fonts/`: Fraunces и Unbounded, Google Fonts, OFL.
