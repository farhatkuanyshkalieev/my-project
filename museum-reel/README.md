# Центр исламской цивилизации — Reels (9:16)

Монтаж вертикального ролика (~57 с) для @olzhabaevva на Remotion.

## Что внутри

- `src/shots.json` — монтажный лист: какой клип/фото, с какой по какую секунду.
- `src/captions.json` — субтитры по фразам с таймингом каждого слова (озвучка, дубль 3).
- `src/Shots.tsx` — кадры: лёгкий наезд на видео, Ken Burns на фото, «панч»-вход на смене смысловых блоков.
- `src/Captions.tsx` — субтитры: слово появляется в момент произнесения, ключевые слова — золотом.
- `src/Titles.tsx` — моушн-титры: «Коран Усмана», «VII век», счётчики 1000+ / 3000+,
  «Медицина / Математика / Астрономия», «2026», плашка Гиннесса, геометка «Ташкент».
- `src/MuseumReel.tsx` — сборка: картинка, грейд/виньетка, озвучка, музыка с приглушением под голос, звуковые эффекты.

## Медиа

Папки `public/clips`, `public/photos`, `public/audio`, `public/sfx` не хранятся в git
(личные исходники и сторонняя музыка). Их нужно положить локально, имена файлов — как в `src/shots.json`
и `src/MuseumReel.tsx`.

## Команды

```bash
npm i
npx remotion studio          # превью и правки
npx remotion render MuseumReel out/museum-reel.mp4 --crf=17
```
