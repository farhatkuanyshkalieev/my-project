# Центр исламской цивилизации — Reels (9:16)

Монтаж вертикального ролика (~52 с) для @olzhabaevva на Remotion.

## Что внутри (v2 — по референсу)

- `src/edit.json` — монтажный лист: 49 кадров, склейки в долю трека (~1 с на кадр), без кадров с ведущей.
- `src/captions.json` — субтитры по фразам с таймингом каждого слова (озвучка ускорена ×1.06, паузы сжаты).
- `src/Edit.tsx` — кадры (зум-удар на склейке, наезд/отъезд) и карточки-вставки как в референсе:
  фото со скруглёнными углами на чёрном + крупная надпись Comfortaa.
- `src/Captions.tsx` — жёлтые субтитры Montserrat строчными, слово появляется в момент произнесения.
- `src/MuseumReel.tsx` — засветки на переходах, крупные слова «медицину / математику / астрономию»,
  тряска на вступлении бита, озвучка, музыка (Beast Inside Beats — Rise Up, склеена под монтаж), звуки.

## Медиа

Папки `public/clips2`, `public/photos`, `public/audio`, `public/sfx` не хранятся в git
(личные исходники и сторонняя музыка). Их нужно положить локально, имена файлов — как в `src/edit.json`
и `src/MuseumReel.tsx`.

## Команды

```bash
npm i
npx remotion studio          # превью и правки
npx remotion render MuseumReel out/museum-reel.mp4 --crf=17
```
