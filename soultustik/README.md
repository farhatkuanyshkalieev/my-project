# soultustik™: рилс для @soultustik

Файл `soultustik_reel.mp4`: 8 с, вертикальный 1080×1920 (Instagram Reels / TikTok), 60 fps, H.264 + AAC.

## Откуда взят стиль

Instagram без входа закрыт. Стиль взят из TikTok бренда (аватар-логотип, био «- cold minded.») и из статьи о бренде на top-news.kz:

- **Цвета:** глубокий зелёный `#024840` и кремовый `#F6F6EA`, сняты пипеткой с логотипа.
- **Логотип:** жирный курсив строчными «soultustik™», векторизован из аватара (potrace). В ролике он объёмный.
- **Название:** soul (англ. «душа») + soltüstik (каз. «север»), то есть «душа севера». Бренд из Костаная.
- **Принты:** впереди райцентры области, сзади карта области. Отсюда свитшот в ролике и карта; контур области на карте стилизован, это не точная граница.
- **Настроение:** «cold minded»: холод, снег, ветер, минус на термометре.

## Раскадровка (120 BPM), версия 2: плотнее и контрастнее

Фон меняется почти на каждой склейке: зелёный, крем, чёрный.

| Время | Кадр | Звук |
|---|---|---|
| 0.0–0.75 | Метель. Компас: стрелка качается и на долю встаёт на **N**. «soltüstik (каз.) — север». Камера ныряет в букву N. | Ветер, ледяной мотив, трещотка стрелки, звон |
| 0.75 | Гигантская **N** на весь кадр: крем, затем инверсия. NORTH / СЕВЕР / SOLTÜSTIK. | Два удара |
| 1.0 | Кремовый кадр: огромное **soul** с контурными эхо. «(англ.) душа». | Тёплый аккорд электропиано |
| 1.375 | Чёрный кадр: **soltüstik** порывом ветра, ледяные эхо. «(каз.) север». | Стеклянный удар, порыв |
| 1.75 | Логотип и «= душа севера», снежный взрыв. | Щелчок, колокольчик |
| 2.0 | Карта области в наклонной камере. Над городами лучи, пунктирный маршрут, гигантский контур «−32°», иней. Перед дропом заикание. | Пины, тиканье, райзер, треск льда |
| 3.0 | **Дроп на кремовом фоне.** Толстый зелёный 3D-логотип, взрыв 3D-кристаллов льда, бегущие строки, роза ветров. На доли стикеры: «cold minded.», круглый значок с компасом, ледяная бирка «−32 °C NORTH SERIES». | Хаус-бит, шлепки стикеров |
| 4.25 | Два кадра-удара: **cold** на чёрном, **minded.** на кремовом. | Удары, свисты |
| 4.5 | Прожектор. Кремовый свитшот падает с ударом и снежным облаком, вокруг кружат кристаллы. Стикеры «front.», затем разворот с размытием и «back.», бирка. | Падение, удар, свист разворота |
| 6.25 | Камера ныряет в логотип на спине. | Свист, обратная тарелка |
| 6.5–8.0 | Финал: логотип, кристаллы на орбите, «cold minded.», компас, значок-стикер, `@soultustik`. | Тёплое разрешение |

## Сборка

```bash
./build_reel.sh   # node + playwright (chromium), python3 + numpy/scipy, ffmpeg
```

- `soul.html`, `soul.js`: сцена. Это 2D-canvas плюс three.js; каждый кадр — функция времени `t`.
- `score_soul.py`: музыка и звуки, синтез без сэмплов. Читает `build/events.json`.
- `render.js`: Playwright → PNG → ffmpeg.
- `assets/soultustik_logo.svg`: векторизованный логотип бренда; `fonts/`: Inter Tight и JetBrains Mono (Google Fonts, OFL).
