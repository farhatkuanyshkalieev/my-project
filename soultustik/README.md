# soultustik™: рилс для @soultustik

Файл `soultustik_reel.mp4`: 8 с, вертикальный 1080×1920 (Instagram Reels / TikTok), 60 fps, H.264 + AAC.

## Откуда взят стиль

Instagram без входа закрыт. Стиль взят из TikTok бренда (аватар-логотип, био «- cold minded.») и из статьи о бренде на top-news.kz:

- **Цвета:** глубокий зелёный `#024840` и кремовый `#F6F6EA`, сняты пипеткой с логотипа.
- **Логотип:** жирный курсив строчными «soultustik™», векторизован из аватара (potrace). В ролике он объёмный.
- **Название:** soul (англ. «душа») + soltüstik (каз. «север»), то есть «душа севера». Бренд из Костаная.
- **Принты:** впереди райцентры области, сзади карта области. Отсюда свитшот в ролике и карта.
- **Настроение:** «cold minded»: холод, снег, ветер, минус на термометре.

## Раскадровка (120 BPM)

| Время | Кадр | Звук |
|---|---|---|
| 0.0–1.0 | Метель. Стрелка компаса качается и ровно на долю встаёт на **N**. Подпись «soltüstik (каз.) — север». Камера ныряет в стрелку. | Ветер, ледяной мотив колокольчиков, трещотка стрелки, звон на «N» |
| 1.0 | Кремовый кадр: **soul** («(англ.) душа»). | Тёплый электропиано-аккорд |
| 1.5 | Зелёный кадр: **soul + soltüstik** («(каз.) север»). | Холодный стеклянный удар и порыв ветра |
| 1.75 | Слова схлопываются в логотип: «= душа севера». | Всасывающий свист, щелчок |
| 2.0 | Карта Костанайской области (контур стилизован). Райцентры загораются по 16-м долям, температура падает до −32°, края покрываются инеем. | Звоны пинов, тиканье, райзер, треск льда |
| 2.94 | Тишина. | Тишина |
| 3.0 | **Дроп.** 3D-логотип, снежный взрыв, ледяная волна, бегущие строки «cold minded. soul of the north.». На доли появляются **cold** и **minded.** | Хаус-бит 4/4, офф-бит саб, морозный пэд, арпеджио колокольчиков |
| 4.5 | Вертикальный свип в студию. Зелёный свитшот поднимается: «front.», впереди райцентры. На 5.5 он разворачивается: «back.», сзади карта области. | Свист ткани, разворот на долю |
| 6.25 | Камера ныряет в логотип на спине (склейка по логотипу). | Свист, обратная тарелка |
| 6.5–8.0 | Финал: объёмный логотип, «cold minded.», «SOUL OF THE NORTH», маленький компас снова находит север, `@soultustik`, «северная душа · Костанай». | Тёплое разрешение: колокольчики, пианино, пэд |

## Сборка

```bash
./build_reel.sh   # node + playwright (chromium), python3 + numpy/scipy, ffmpeg
```

- `soul.html`, `soul.js`: сцена. Это 2D-canvas плюс three.js; каждый кадр — функция времени `t`.
- `score_soul.py`: музыка и звуки, синтез без сэмплов. Читает `build/events.json`.
- `render.js`: Playwright → PNG → ffmpeg.
- `assets/soultustik_logo.svg`: векторизованный логотип бренда; `fonts/`: Inter Tight и JetBrains Mono (Google Fonts, OFL).
