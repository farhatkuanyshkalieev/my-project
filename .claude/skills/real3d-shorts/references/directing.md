# Режиссура: картинка на каждую фразу, камера всегда в движении

## 1. Принципы
1. **Одна фраза — один шот.** Длинная фраза (> 4 с) — 2 шота или шот + вставка.
2. **Смена мира каждые 1–2 фразы:** новая локация, вставка «внутри» (рентген, макро, схема), флешбек,
   смена времени суток. В ролике минимум **3 разных мира** и **1–2 вставки-рентгена**.
3. **Камера всегда движется.** Статика > 1 с запрещена (кроме намеренной паузы-удара перед поворотом).
4. **Тип движения меняется от шота к шоту:** нельзя два наезда подряд, два облёта подряд.
5. **Склейка на действии.** Режь в момент движения (рука пошла, предмет падает), а не после.
6. **Ударные слова = событие в кадре:** падение, вспышка, rack-focus, резкое приближение.
7. **Первый кадр — самый сильный:** крупно, движение уже идёт, деталь эффекта (пар, искры, вода).

## 2. Каталог движений камеры (kit/camera.py → `move(...)`)
| Имя | Что делает | Когда |
|---|---|---|
| `push_in` | медленный наезд на лицо/предмет | эмоция, осознание |
| `pull_back_down` | отъезд + опускание, предмет переднего плана въезжает в кадр | открытие сцены |
| `crane_up` | подъём вверх и назад, мир становится маленьким | финал, одиночество |
| `orbit` | облёт 3/4 вокруг героя на 40–90° | объяснение, «вскрытие» механизма |
| `track_side` | камера едет параллельно движению героя | ходьба, бег, процесс |
| `low_follow` | у самой земли за падающим предметом | падение, удар |
| `snap_zoom` | резкий наезд за 6–8 кадров + моушен-блюр | ударное слово, шок |
| `whip` | быстрый поворот на 30–60° за 5–6 кадров (переход к следующему шоту) | смена мира, «тем временем» |
| `rack_focus` | фокус перетекает с дальнего на ближний объект | связь двух вещей |
| `xray_glide` | плавный проезд вдоль органа/руки внутри рентгена | механизм |
| `dolly_zoom` | наезд + уменьшение фокусного (эффект «вертиго») | тревога, внезапность |

Всем движениям добавляется **ручная тряска** (`handheld=0.3–1.0`) — живая камера. Для спокойных
шотов 0.3, для тревожных 0.8–1.0. Объективы: 24–32 мм для общих и низких планов, 40–55 мм для лиц,
70–85 мм для деталей. Диафрагма f/1.8–2.8 у лиц (сильное боке), f/4 на рентгене.

## 3. Анти-скука (проверь перед аниматиком)
- [ ] Нет двух одинаковых крупностей подряд (общий → средний → крупный → деталь чередуются).
- [ ] Нет двух одинаковых движений подряд.
- [ ] Минимум 3 мира, 1+ рентген/вставка.
- [ ] В каждом шоте что-то **меняется**: падает, вспыхивает, растёт, тает, загорается.
- [ ] Средняя длина шота 3–5 с, ни одного длиннее 7 с без внутренней смены (rack focus / новое событие).
- [ ] Минимум 1 переход `whip` или `snap_zoom` на ударном слове.

## 5. Актёрская игра (мимика и тело) — гипербола, а не реализм
- **Эмоции гиперболизированные**: на полшага «больше, чем в жизни», как у анимационных персонажей.
  Если эмоцию нельзя назвать по стоп-кадру без звука — усиливай (`face.INTENSITY`, позы тела ярче).
- Позы тела тоже преувеличены: холод — плечи к ушам, сильная дрожь; облегчение — плечи падают, голова запрокинута;
  шок — отшатнулся назад, руки к лицу.
- В shot list у каждого шота с героем колонка **«эмоция»**: cold / pain / fear / surprise / drowsy / relief / focus / sad / smile.
- Эмоция меняется вместе с текстом: страх → боль → облегчение → тревога. Одна эмоция весь ролик — мёртвый герой.
- Тело поддерживает лицо: холод — плечи вверх, дрожь; облегчение — плечи опускаются, голова назад;
  слабость — покачивание, колени. Руки всегда чем-то заняты (греют, держат, тянутся).
- На крупном плане лица — минимум одно **событие мимики** (моргнул и открыл глаза шире, сжал зубы, выдохнул).

## 6. Свет и настроение
- Ночь/холод: холодный контровой (area, 0.6/0.75/1.0) + тёплый практический источник (фонарь, окно)
  + слабый заполняющий. Фон тёмный, герой отделён контровым.
- Жар/тревога: тёплая подсветка лица снизу-сбоку, красный акцент, усиление сердцебиения в звуке.
- Рентген: тёмно-синий градиентный фон, голубой контур кожи, красные светящиеся сосуды.
- Экспозиция −0.3, AgX Medium High Contrast. Дымка — бокс, плотность 0.004–0.006.
