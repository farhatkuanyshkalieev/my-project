# Сценарий: формула, хук, проверка

Цель — зритель не листает дальше в первую секунду и досматривает до конца. Формула выведена из разбора
десятка вирусных 3D-объяснялок (только структура и ритм — тексты, сюжеты и формулировки чужих роликов
**не используем**).

## 1. Параметры
| Параметр | Значение |
|---|---|
| Длина | 80–125 слов → 30–45 с при темпе диктора ~2,7 слова/с |
| Фраза | 6–16 слов, одна мысль, одна картинка |
| Абзацы | 7–10 фраз = 7–10 шотов (+ 1–3 вставки-перебивки внутри длинных фраз) |
| Лицо | 3-е лицо («он», «они», «мужчина») или 2-е («ты», «представь») — никакого «я» |
| Вступление | **нет**. Ни «сегодня расскажу», ни «знали ли вы». Первое слово — уже действие |

## 2. Скелет (5 тактов)
1. **Хук-действие (0–3 с).** Конкретная физическая картинка в разгаре событий: кто-то что-то делает
   прямо сейчас, и это странно, опасно или непонятно. Зритель должен увидеть кадр по одной фразе.
2. **Цепочка (3–15 с).** 2–4 коротких шага «потом… поэтому… пока…» — события нарастают, каждое
   следующее неожиданнее. Глаголы движения, а не состояния.
3. **Поворот «Понимаете,» / «Дело в том, что» (15–28 с).** Скрытый механизм: что происходит внутри
   тела, устройства, системы. Это место для вставки-рентгена/схемы. Одно ясное объяснение, без терминов
   (или термин + тут же простыми словами).
4. **Последствие (28–38 с).** Что из этого вышло — конкретно и зримо.
5. **Удар-вывод (последние 3–5 с).** Короткая фраза, которую хочется переслать: практический вывод,
   мораль или вопрос к зрителю. Без «подписывайтесь».

## 3. Типы хуков (бери самый сильный для темы)
- **В разгаре:** «Мужчину трясло от холода, и он дышал в ладони…» — герой, действие, деталь.
- **Процесс:** «Они взяли… потом подключили… и запустили…» — эксперимент/изобретение шаг за шагом.
- **Представь:** «Представь, что ты…» — зритель сам герой, ставка личная.
- **Парадокс:** утверждение, которое звучит неправильно («Чтобы согреться, он разделся»).
- **Если бы:** «Если повредить вот эту часть мозга…» — условие с жутким следствием.
- **Обманка:** зритель уверен, что знает, чем кончится, — поворот ломает ожидание.

## 4. Как найти угол темы
Для любой темы ищи **«скрытый механизм + человеческая ставка»**:
- Что происходит **внутри** (тела, машины, общества), чего не видно глазами?
- Где здесь **человек**, которому плохо/страшно/неожиданно хорошо?
- Какой **один факт** заставит сказать «да ладно»? Он идёт в поворот.
- Какой **практический вывод** можно унести? Он идёт в финал.

Предлагая пользователю углы, пиши: `Хук: «…» → Узнают: … → Финал: …`.

## 5. Правила текста под голос и субтитры
- Числа словами в `voice.txt`, цифрами в `voice_display.txt` (субтитры).
- Без скобок, кавычек-ёлочек внутри фраз, аббревиатур (TTS читает плохо).
- Тире «—» для паузы-удара, многоточие — нельзя (TTS тянет).
- Ударные слова (на них камера/звук делают акцент) — отметь в раскадровке.
- Каждая фраза должна **рисоваться**: если её нельзя показать — перепиши.

## 6. Проверка перед показом пользователю
- [ ] Первая фраза — действие и картинка, без вступления.
- [ ] Есть поворот с механизмом, который зритель вряд ли знал.
- [ ] Каждая фраза → отдельный кадр, минимум 3 разные локации/вставки.
- [ ] Факты проверены (для медицины/науки — источник найден).
- [ ] Финал — короткий, пересылаемый, без призывов.
- [ ] 80–125 слов.
