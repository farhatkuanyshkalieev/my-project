# Real3D Shorts — скилл для Claude Code

Делает вертикальный шортс (35–50 с) по вашей теме: реалистичные 3D-люди, атмосферные локации,
рентген-вставки «внутри тела», гиперболизированная мимика, динамичная камера, озвучка ElevenLabs,
субтитры, музыка и звуки.

## Что нужно
Только **Blender 5.1+** с включённым **MCP-мостом** (расширение «MCP» от Blender Lab, Auto Start).
Всё остальное (Node.js, ffmpeg, генератор людей MPFB, ассеты, Remotion, whisper) скилл поставит сам.
Для озвучки ElevenLabs — аккаунт и расширение Claude in Chrome (иначе бесплатный голос Piper).

## Установка
Распакуйте папку `real3d-shorts` в `~/.claude/skills/` (Windows: `%USERPROFILE%\.claude\skills\`)
и откройте новый чат Claude Code. Напишите: «Сделай шортс про <тема>».

## Как идёт работа
1. Проверка и автоустановка (первый раз 5–15 минут).
2. 3 варианта хука → сценарий + раскадровка → ваше «ок».
3. Озвучка → тайминги → постановка в Blender.
4. Аниматик Workbench за 2–5 минут → ваше «ок» на движение.
5. Финальный рендер (≈ 2,5–3,5 часа на 45 с) → монтаж → готовый mp4.
