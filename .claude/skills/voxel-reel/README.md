# voxel-reel — скилл для Claude Code

Делает вертикальный рилс в воксельном стиле (Blender + ffmpeg + Remotion) по приблизительному сценарию: интервью → персонажи из фото → аудио и пословный тайминг → тест липсинга → локации → аниматик → стоп-кадры → превью → финал → субтитры → отчёт.

## Установка
Распакуй папку `voxel-reel` в `~/.claude/skills/` (глобально) или в `<проект>/.claude/skills/`. В Claude Code скилл появится как `/voxel-reel`; также срабатывает сам на «сделай воксельный рилс…».

## Что нужно на машине
- Blender 4.2+/5.x (MCP-аддон опционален — пайплайн работает headless через `blender -b … --python`).
- ffmpeg 8+ с фильтром `whisper` + ggml-модель whisper (путь указывается в `script.json`).
- Node 18+ — только для субтитров Remotion.
- Диск с ≥15 ГБ под рендеры.

## Важно про пути
`scripts/lib/sound_build.py`, `compose.py`, `qa_reel2.py` и все `scripts/reference_reel01/*.py` содержат константу пути проекта (`R = r"E:\…\reel01"`, `RP`, `DP`) из ролика-образца — при копировании в новый проект замени её на свои папки (первые строки файла). Библиотеки `vx_lib.py`, `anim_lib.py`, `lipsync_lib.py`, `face_visemes.py`, `street_v2.py`, `npc_build.py`, `eevee_presets.py` путей не содержат (кроме шрифта `C:\Windows\Fonts\arialbd.ttf` в `face_visemes`/`r2_fx` — замени на любой жирный TTF с кириллицей).

## Состав
- `SKILL.md` — инструкция для Claude (интервью, порядок, правила, самопроверка).
- `scripts/audio_pipeline.py`, `scripts/face_from_photo.py` — универсальные утилиты.
- `scripts/lib/` — библиотеки сцены, улицы, персонажей, липсинга, звука, композа, QA, рендера.
- `scripts/reference_reel01/` — полный код ролика-образца (сборка сцены, Claude, эффекты, камеры, свет, концовка).
- `scripts/subs/` — Remotion-субтитры (композиция + генератор страниц).
- `assets/Template_Room.blend` — эталонная комната + герой + Claude-маскот.
- `references/` — формат сценария, команды пайплайна, чек-лист, стиль.
- `example/` — сценарий, тайминг и контакт-лист готового ролика.
