# Чек-лист перед каждым показом (✅/❌, с тем, как проверено)

**Липсинг**
- слоги совпадают со звуком, рот опережает на 1 кадр (генератор `lipsync_lib.frames(lead=1)`);
- нет форм короче 2 кадров (`min hold` ≥ 2 в выводе генератора);
- в паузах >0,3 с рот закрыт (`X` в треке);
- челюсть/подбородок двигаются вместе с губами (ключи `V_*` деформируют нижнюю часть лица);
- эмоции работают одновременно с речью; моргания раз в 2–4 с + после резких поворотов и смены эмоции.

**Анимация**
- нет Т/А-позы (`qa_reel2.py` → `tpose_count` 0; переходные 1–2 кадра допустимы, отметь);
- в диалоге герой не стоит столбом: переминание, жесты, взгляд на собеседника;
- Claude: без ног, один цвет, летает вокруг при объяснении, движения механические; рот исчезает в тишине;
- пересечений с героем 0 (`hit_counts`), Linear-ключей на герое 0.

**Камера**
- нет статичных отрезков >6 кадров вне сцены паузы (`static_count` 0);
- whip pan ≤ 6 кадров размытия; на каждом шаге новый ракурс и новое движение;
- персонаж ≥ 1/3 высоты кадра на средних планах; нет полукадра пустой стены/неба.

**Мир**
- на фасадах есть детали, машины не коробки, край мира не виден (4 ракурса), небо без «синей стены»;
- нет полностью чёрных кадров; свет не рыжий и не синий; лица читаются в каждой сцене.

**Графика и звук**
- шаги/эффекты появляются ровно на своих словах (кадры из `timing.json`);
- голограммы/подписи читаемы на телефоне (≥60 px высоты текста), не закрывают лицо;
- безопасные зоны (верх 220 / низ 400 / право 140 px);
- −14 LUFS ±0,5, true peak ≤ −1 dBTP (`ebur128=peak=true`); голос разборчив поверх музыки (ducking −9 дБ);
- последние 1,5 с свободны под плашку (или своя концовка по ТЗ).

**Как смотреть самому**
- контакт-лист всего ролика раз в 0,5 с; полосы кадров вокруг ключевых событий (`select=not(mod(n,2))`, `tile=6x1`);
- крупные полосы рта на ударных словах и паузах (crop зоны рта);
- стоп-кадр каждой сцены в финальном качестве.
