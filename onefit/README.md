# 1Fit: рекламный моушн-ролик

Файл `1fit_ad.mp4`: 22 с, вертикальный 1080×1920, 60 fps, H.264 + AAC, с озвучкой.

## Откуда взят стиль

Источники: сайт 1fit.app, их TikTok @1fit.app и рекламные материалы.

- **Логотип:** белое жирное «1FIT» курсивом на синей «таблетке» `#3447F6`. Взят с их сайта (`assets/1fit_logo.svg`).
- **Палитра:** королевский синий, фиолетовые `#4C27DE` / `#7D5DFF`, розовые `#F65BAF` / `#FCA2FE`, голубой `#44C7FF`, красный `#F14635`, золото `#E9D290`.
- **Подача:** глянцевый 3D (хромированное «365», карты абонемента), плоские цветные категории спорта, тёмный интерфейс приложения.
- **Месседжи:**
  - «Абонемент на все виды спорта»;
  - 1406+ залов «рядом с домом или работой»;
  - «скачай → выбери → отсканируй QR на входе»;
  - рассрочка;
  - бесплатные гостевые для друзей;
  - «Сегодня — лучшее время для старта».

## Озвучка

ElevenLabs eleven_v4, голос Andrey Permikin (энергичный, харизматичный).

> Один абонемент — все виды спорта! Зал. Бассейн. Йога. Танцы. Бокс. Кроссфит. Больше тысячи четырёхсот залов — рядом с домом и работой. Открыл приложение, отсканировал QR-код — и ты уже на тренировке! Рассрочка без переплат и бесплатные гостевые для друзей. 1Fit. Сегодня — лучшее время для старта!

Тайминги слов распознаны локально (faster-whisper, `vo/words.txt`). Все склейки и анимации стоят ровно на словах (`vo/cues.js`).

## Сборка

```bash
npm install          # three.js 0.160
./build_reel.sh      # node + playwright (chromium), python3 + numpy/scipy, ffmpeg
```

- `fit.html`, `fit.js`: сцена (three.js + 2D-canvas, каждый кадр — функция времени `t`).
- `score_fit.py`: музыка и звуки, синтез без сэмплов, сведение с голосом и приглушение музыки под ним.
- `vo/`: дубль озвучки, тайминги слов, `cues.js`.
- `render.js`: Playwright → PNG → ffmpeg (4 параллельных процесса).
