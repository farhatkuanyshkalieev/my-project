# «Опиши мне» — вертикальный анимационный шорт (9:16, 100 с)

Тимур фотографирует Миру на крыше. Она никогда не снимает зелёные очки
и всё время просит его: «опиши мне закат». Она теряет зрение и уходит,
чтобы он не остался с ней из жалости. Через три года он садится рядом
с ней на той же крыше и описывает закат теми же словами. Себя он так
и не называет: молча вкладывает ей в ладонь её зелёные очки.

**Формат:** 1080×1920, 60 fps, 100.0 с, H.264 + AAC. Готовый файл: `deliverables/`.

- **Персонажи** нарисованы с нуля по референсам в угловатом cel-стиле (`src/rig`): Мира (`Mira.tsx`) и Тимур (`Timur.tsx`).
- **Голоса:** ElevenLabs v4 через Higgsfield (Vlad и Xenia). Липсинк строится по огибающей реального голоса.
- **Звук** (`tools/sound.py`): под репликами нет эффектов. Звучат только действия в кадре между репликами, а музыка синтезирована (фетровое фортепиано, струнные, челеста).
- **Моушн-графика** (`src/mg`): титр шрифтом Брайля, видоискатель, полароид, «сок» на небе, туннельное зрение, заключение врача, расколотый экран, записка от руки, переход через линзы очков.

```bash
npm install
python3 tools/vo_analyze.py && python3 tools/sound.py
npx remotion render Main out/opishi.mp4 --props='{"withAudio":true}' --crf=17
npx remotion still CardMira out/card_mira.png
npx remotion still CardTimur out/card_timur.png
```
