# Kaidarova (@kaidarova.ethnic): моушн-клип «MAHABBAT / Завёрнутые в любовь»

Файлы:
- `kaidarova_reel.mp4`: 18 с, вертикальный 1080×1920, 60 fps, H.264 + AAC, с треком;
- `kaidarova_reel_no_music.mp4`: та же картинка, только звуки. В неё можно поставить лицензированный трек из Instagram: монтаж стоит на сетке 120 BPM.

Сценарий с идеей лежит в [`SCENARIO.md`](SCENARIO.md).

## Что изучено

Instagram без входа закрыт, поэтому материал взят из открытых источников: Threads @kaidarova.ethnic, The Astana Times (2019), WE Project, Digital Business.

- **Бренд.** «Kaidarova | Atelier», 14.7K подписчиков в Threads. «Заманауи этника · стилизуем этнику · авторлық принттер · Астана, Сығанақ 15». Логотип: перо филина үкі (оберег) и «Kaidarova · made in Kazakhstan with love». Самые узнаваемые вещи: принт MAHABBAT и кардиганы Oyu. Были коллекции «Красная книга» и «Set Qudalyk».
- **Основательница — Нагима Кайдарова:**
  - графический дизайнер (ЕНУ им. Гумилёва);
  - в 2014 году начала с футболок с принтом тумара-оберега, печатала на оборудовании для билбордов;
  - одной из первых стала писать казахские слова латиницей на одежде. О MAHABBAT говорит: «хотела, чтобы девушки были завёрнуты в любовь»;
  - для индивидуального пошива строит 3D-модель клиентки;
  - ездит верхом, снималась в «Томирис».

Не путать с алматинским брендом MAHABBAT Сабины Виттер: это другая компания.

## Решения

- **Главная мысль — оберег и любовь.**
  - Перо үкі из логотипа открывает клип: его бородки срываются нитями.
  - В финале перо возвращается и садится в логотип.
  - Слово MAHABBAT буквально заворачивает собой мир: сначала 3D-лентой, потом принтом платья.
- **3D только в одном месте:** спираль-лента со словом MAHABBAT вокруг невидимой фигуры, с мягкими тенями. Надпись читается с обеих сторон ленты. Камера ныряет сквозь неё на дропе.
- **2D:**
  - перо (контур и надпись векторизованы с аватара, бородки нарисованы кодом и анимированы);
  - всепринт MAHABBAT, из которого выходит модель в настоящем платье Mahabbat;
  - узор Oyu, связанный петля за петлёй, с кареткой вязальной машины;
  - тумар золотой линией с их платьем-тумаром внутри.
- **Одна история без склеек.** Каждая сцена передаёт следующей предмет:
  - бородки пера слетаются в начало 3D-ленты;
  - нырок сквозь ленту продолжается зумом принта;
  - слово MAHABBAT распускается в нить, которая кормит вязальную каретку;
  - связанное полотно ложится точно на кардиган в их кадре в степи;
  - степь закрывается треугольником тумара;
  - перо-подвеска тумара улетает вверх и падает в логотип финала.
- **Тумар.** Тёмно-бордовый фон, вращающиеся золотые лучи, пыль, светящийся контур, блик, качающиеся подвески.
- **Текст под телефон.** Подписи от 40 px, крупные курсивные строки, длинные фразы в две строки.
- **Финал.** Крупный логотип Kaidarova держится около 2.5 с, внизу подпись автора «made by @f4rh4t._».
- **Звук:** тёплый этно-хаус, 120 BPM, ре минор.
  - Вокальный хук «ма-хаб-бат» из синтезированных слогов, домбра в технике «қағыс», кобыз, горловое пение и бубен под тумар.
  - Щелчки вязальной каретки, дроп на проходе сквозь ленту.
  - Синтез кодом, без сэмплов. Шёпот «Махаббат» (ElevenLabs) подключится сам, если положить `vo/whisper.wav`.

## Сборка

```bash
npm install          # three.js 0.160
./build_reel.sh      # node + playwright (chromium), python3 + numpy/scipy, ffmpeg
```

- `kaidarova.html`, `kaidarova.js`: сцена.
- `score_kaidarova.py`: трек и звуки. Третьим аргументом пишет версию без музыки.
- `assets/`: перо, надпись, слоган (векторизованы с аватара) и `feather_rows.json` (геометрия бородок).
- `img/`: их фото (кардиган Oyu, платье-тумар, платье Mahabbat).
- `cut/mahabbat.png`: вырезка модели в платье Mahabbat.
- `fonts/`: Oswald, Cormorant Garamond, Jost (Google Fonts, OFL).
