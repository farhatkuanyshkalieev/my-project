# Kaidarova (@kaidarova.ethnic): fashion-промо «Завёрнутые в любовь»

Файлы:
- `kaidarova_promo.mp4`: 18 с, вертикальный 1080×1920, 60 fps, H.264 + AAC, с треком;
- `kaidarova_promo_no_music.mp4`: та же картинка, только звуки. Монтаж стоит на сетке 120 BPM, поэтому в Instagram под неё можно поставить лицензированный трек.

Сценарий с идеей лежит в [`SCENARIO.md`](SCENARIO.md).

Первая версия (`kaidarova_reel*.mp4`, `kaidarova.js`, `score_kaidarova.py`) не понравилась. Пользователь сказал, что графика дешёвая и слишком абстрактная. От неё в новой версии осталась только цитата основательницы.

## Материал

- **Фото и видео.** Скриншоты постов и запись Reels из Instagram бренда прислал пользователь: самому сервису Instagram закрыт без входа.
  - Фото обрезаны от интерфейса, счётчики «1/5» и «4/4» затёрты.
  - Всё увеличено в 4 раза нейросетью 4xNomosWebPhoto (ESRGAN, ONNX).
- **Их подписи.**
  - «MAHABBAT // JAÑA TÜS»;
  - «терең әрі қаңық бургунди», то есть глубокий насыщенный бордовый;
  - «қанық қызыл мен жұмсақ беж», то есть насыщенный красный и мягкий беж;
  - «Шектеулі топтама, бар болғаны 3 дана», то есть лимитированная коллекция, всего 3 штуки: шерсть, шёлковая подкладка;
  - «Наши кардиганы "Ою" — это про связь».
- **Основательница — Нагима Кайдарова.**
  - С 2014 года, Астана.
  - О принте MAHABBAT говорит: «хотела, чтобы девушки были завёрнуты в любовь» (The Astana Times).

## Решения

- **Одежда в каждом кадре.** Символов без вещей нет: всё построено на их фото и видео.
- **Цитата — кинетический постер.** Каждое слово бьёт в центр на долю бита и встаёт на место. В буквах «ЗАВЁРНУТЫ» виден красный свитер.
- **Переходы из их же вещей.** Кадр заворачивает полоса вязаного MAHABBAT, затем бежевый шарф. Шторка финала тоже вязаная.
- **Лукбук.** Журнальная вёрстка с номерами образов и подписями на казахском с русским переводом. Склейки идут на бит: сплит-скрин, whip с размытием, карточка, триптих.
- **«Ою».** Их ролик про три поколения женщин и фраза «завёрнутые в любовь» над семьёй.
- **Финал.** Крупный логотип, @kaidarova.ethnic, подпись автора `made by @f4rh4t._`.
- **Звук.** Этно-хаус на 120 BPM в ре миноре: удар на каждое слово, хук «ма-хаб-бат», домбра «қағыс», кобыз в части «Ою». Всё синтезировано кодом.

## Сборка

```bash
npm install          # нужен только для render.js (playwright)
./build_promo.sh     # node + playwright (chromium), python3 + numpy/scipy, ffmpeg
```

- `promo.html`, `promo.js`: сцена, 2D canvas. Каждый кадр — функция времени; кадры видео подгружает `window.prep(t)`.
- `score_promo.py`: трек и звуки. Третьим аргументом пишет версию без музыки.
- `promo/img/`: их фото, обрезанные и увеличенные.
- `promo/clips/`: куски их Reels, обрезанные и увеличенные, 30 fps.
- `assets/`: перо, надпись и слоган, векторизованы с аватара.
- `fonts/`: Oswald, Cormorant Garamond, Jost (Google Fonts, OFL).
