**Настоящие 60 fps.** Каждый кадр рисуется заново для своего момента времени (T = n/60): риг, камера, свет, пар, часы, мимика — без интерполяции и без дублирования кадров. Проверка на мастере без зерна: из 3592 переходов (без финального титра) полностью идентичны 79 (2.2 %) — это намеренные паузы: чёрный экран 0.00–0.33 с, удержание прочитанного уведомления в S01 и замирание в S13. В финальных файлах из-за временного плёночного зерна дубликатов 0.

## Как сделано
1. **Инструменты (этап 1).** Higgsfield: на счёте 0.11 кредита (free) → генерация видео/изображений невозможна. ElevenLabs (подключён) → озвучка. Локально: ffmpeg 6.1, Python + skia-python (векторная отрисовка), numpy/scipy (звук), faster-whisper (контроль реплик), Chromium (не понадобился). GPU нет.
2. **Анимация** — собственный 2.5D-движок (`scripts/engine/`): параметрический риг стикмена (IK рук, поворот головы 2.5D, веки и брови вырезают глаз через PathOps, зрачки с саккадами, моргание, дыхание, микродвижения головы, анти­ципация/overshoot/ease, squash), липсинк по огибающей реального голоса, сеты с фиксированной географией, параллакс, глубина резкости, мультипликативный проход освещения (тёплая лампа / холодное окно), цветокор по сценам, глитч-исчезновение мамы со сдвигом слайсов и RGB-split, whip pan с motion blur.
3. **Озвучка** — ElevenLabs `eleven_v4` с режиссёрскими тегами для каждой реплики (`scripts/voice_takes.py`): Арман — Egor (молодой, разговорный); Двойник — тот же актёр, −1.3 полутона (rubberband с сохранением форманты) + реверберация коридора; Мама — Soldani (тёплый зрелый, лёгкий казахский акцент), реплики по телефону — полоса 320–3300 Гц + лёгкая цифровая деградация. Каждый дубль проверен Whisper: все выбранные дубли совпадают с текстом (сходство 0.95–1.00). Отбракованы: «Вам?» вместо «Мам?» (A04 дубль 2), «Х-х-х-что» (A07 дубль 2).
4. **Звук** — вся музыка и все эффекты синтезированы в `scripts/audio_build.py` (оригинальные, без чужих сэмплов): мотив музыкальной шкатулки E–C–B–G#, пульс 84/96 BPM, дроны, кластер на появлении двойника, почти полная тишина перед голосом из коридора, жёсткий обрыв звука на склейке в чёрное. Эффекты: пинг уведомления, вибро по столу, оригинальный рингтон, стук кружки, скрип стула, гул/треск лампы синхронно с миганием, глитч + суб-удар на исчезновении, тапы клавиатуры, свуш отправки, сердцебиение, шаг двойника, тиканье часов, room tone. Музыка дакается под диалог, лимитер, loudnorm (2 прохода).
5. **Монтаж** — 23 кадра, общая шкала времени `scripts/ep01_timeline.py` для картинки и звука (синхронизация гарантирована): хук в первые 0.5 с, rack focus, реверсы через плечо с соблюдением правила 180°, инсерты телефона, POV пустого стула, sound bridges (рингтон через склейки), match cut, whip pan в коридор, обрыв в чёрное.

## Известные ограничения
- **ElevenLabs отключил Free Tier на аккаунте** во время работы («Unusual activity… proxy or VPN»; облачная среда работает через прокси). Все 14 реплик успели сгенерироваться (23 дубля), но новые дубли/правки голоса сейчас невозможны без платной подписки. У реплик M03, M04, M05, D01, D02 только по одному дублю.
- Higgsfield: 0.11 кредита — не использовался.
- Голоса Девочки, Баристы и Оператора к сериям 2+ ещё не кастингованы.
- Звук проверен объективно (громкость, спектр, стемы, распознавание речи), но не на слух.

## Как продолжать сериал
- Новая серия = новый `epNN_timeline.py` + `epNN_shots.py`; риг, сеты, UI телефона, звуковые функции, палитры и голоса переиспользуются.
- Пересобрать: `audio_build.py → render.py → subtitles.py → finalize.py → qc.py → make_manifest.py`.
- Поправить одну сцену: функция `sNN` в `scripts/ep01_shots.py`; превью кадров — `render_stills.py OUT T1 T2 …`.
