# Визуальная основа v2 «concept» — отчёт

Цель: привести внешний вид «ТЕБЯ ЗДЕСЬ НЕ БЫЛО» к утверждённому концепту `references/concept/original_concept.png`.
Сценарий, голоса и структура истории **не менялись**. Производство серии 2 **не начиналось** — сначала нужно ваше утверждение этой основы.

## 1. Чем сделана серия 1 и какие инструменты доступны

|---|---|---|
| Собственный рендерер (Python + skia, `scripts/engine/`) | процедурная 2.5D-анимация, риг, 60 fps без интерполяции, липсинк | ✅ этим сделана серия 1 |
| ElevenLabs | озвучка | free tier отключён сервисом (см. отчёт серии 1) |
| **Canva** `generate-image` | **reference-to-image** (до нескольких референсов) | ✅ использован: 2 генерации, затем `quota_exceeded` (бесплатная квота исчерпана) |
| Higgsfield | Seedance 2.0/2.5, Kling 3.0 (reference elements = фиксированные персонажи), MiniMax H3 — **image-to-video, character consistency** | ❌ 0.11 кредита, unlimited недоступен |
| OpenArt | Kling 4.0/3 Omni element-to-video, Seedance 2.x, Veo 3.1, Wan 3.0, Nano Banana / GPT Image (reference-to-image) | ❌ 0 кредитов |
| HyperFrames / Motion | код-анимация графики, без генерации персонажей | не подходит |

## 2. Выбранная технология
**Гибрид: AI reference-to-image для фиксации дизайна + процедурный риг v2 для анимации.**
- Canva сгенерировал по концепту эталонные развороты Армана и двойника (`references/v2/ai_canva/`).
- Риг v2 (`scripts/engine/rig2.py`) воспроизводит эти эталоны по замерам; пост-обработка `scripts/engine/look.py` даёт «живописный» вид (bloom, мягкость, текстура, плёночный тон, зерно).
- Почему не image-to-video для персонажей: (1) нет кредитов; (2) даже с кредитами генеративное видео «плывёт» в лице/пропорциях между планами, не даёт нативных 60 fps и точного липсинка под готовую озвучку; риг гарантирует идентичность в каждом кадре. Если кредиты появятся, рекомендую Kling 3.0/4.0 (element references) или Seedance 2.0 с нашими листами как референсами — для **фоновых живописных плейтов и отдельных B-roll**, а не для говорящих персонажей.

## 4. Зафиксированный дизайн (кратко)
- **Арман**: голова — матово-чёрный круг R; глаза в нижней половине, белые, верхнее веко срезает 16% с наклоном 16°, зрачки 0.115R; **белые толстые брови**, резко наклонены к переносице; маленький тёмный рот; чёлка с 3 кончиками справа, подсвеченная контуром; **контур = цвет ключевого света** (на кухне золотой #ffae55) по всему силуэту + ореол; чёрная рубашка, воротник, **бежевый галстук #b9a07c**, крупные чёрные перчатки-руки с пальцами; короткая шея — голова сидит на воротнике.
- **Двойник**: тот же силуэт; красный контур и ореол #ff2a2a; глаза — бело-горячий центр с красным краем и сильным свечением, веко 33%; тёмно-красный галстук.
- **Мама**: фарфоровое лицо #ecdccf; тёмно-каштановые волосы с пробором по центру, пучок сзади-сверху, пряди у висков; уши; большие тёмно-карие глаза с ресницами; бежевый верх и графитовый фартук.

## 6. Отличия, которые остаются в take3 (честно)
1. **Фон проще концепта**: в концепте — детально прописанная живописная комната (текстуры дерева, складки штор, лампа, растение в фокусе); у нас — упрощённый векторный интерьер под размытием и пост-обработкой. Это главное оставшееся отличие; полностью устраняется только генеративными живописными плейтами (нужны кредиты Canva/OpenArt/Higgsfield).
2. **Объёмная светотень на одежде и руках** в концепте мягче и «трёхмернее»; у нас одежда почти плоская.
3. **Ореол контурного света** у нас шире и ровнее, в концепте — тоньше и неравномернее.
4. **Мама** сделана по карточке концепта без AI-эталона (квота Canva закончилась) — сходство ниже, чем у Армана и двойника; волосы и пропорции лица нуждаются в утверждении.
5. Кисти держат телефон схематичнее, чем в концепте.

Полного совпадения с концептом **нет**; достигнуто близкое соответствие по персонажам (силуэт, голова, глаза, брови, одежда, контурный свет, палитра) и по общему освещению.
