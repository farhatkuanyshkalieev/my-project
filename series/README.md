# ГРЯЗНЫЕ МИЛЛИОНЫ — мини-сериал для Reels

Вертикальный мини-сериал 1080×1920, 60 fps, по 60 секунд на серию.
Каждая серия собирается кодом: персонаж, фоны, инфографика и вся моушн-графика
нарисованы в SVG/React (Remotion), музыка и звуки синтезируются скриптом,
озвучка — живой мужской голос из ElevenLabs.

Сюжет: герой только что украл 10 миллионов наличными. Каждая серия разбирает
одну причину, почему такие деньги становятся ловушкой и как человека в итоге
находят. Формат: «проблема → инфографика → последствие → клиффхэнгер».

## Как устроен проект

```
series/
  src/episodes/ep01/cues.json   ← единый таймлайн: сцены, биты, рост «розыска»
  src/episodes/ep01/Ep01.tsx    ← сборка серии
  src/episodes/ep01/scenes/     ← сцены серии
  src/components/               ← персонаж, реквизит, HUD, субтитры, переходы, эффекты
  audio/score.py                ← музыка и звуки по cues.json
  audio/mix.sh                  ← сведение: голос + музыка с дакингом + звуки, −14 LUFS
  public/ep01/vo.mp3            ← озвучка (ElevenLabs, голос Mikhail, модель eleven_v4)
  public/ep01/words.json        ← тайминги слов для субтитров
```

`cues.json` читают и видео, и аудио-скрипт, поэтому удары, штампы и звуки
всегда совпадают. Чтобы сдвинуть момент, меняется одна цифра.

## Сборка

```bash
cd series
npm install
python3 audio/score.py src/episodes/ep01/cues.json public/ep01   # музыка + звуки
audio/mix.sh public/ep01 0.15                                    # финальный микс
npm run render:ep1                                               # → out/ep01.mp4
```

Быстрые кадры для проверки: `node scripts/stills.mjs out/qa 5.2 22.6 49.0`, затем
`python3 scripts/sheet.py out/qa out/sheet.jpg`.

В облачной среде Remotion использует предустановленный Chromium
(`remotion.config.ts`), потому что скачать свой браузер ему не даёт сеть.

## Следующая серия

1. Скопировать `src/episodes/ep01` в `ep02`, переписать `cues.json` и сцены.
2. Сгенерировать озвучку тем же голосом (Mikhail, `eleven_v4`), получить тайминги
   слов (ElevenLabs Speech-to-Text) и положить в `public/ep02/`.
3. Подставить реальные тайминги в `cues.json`, прогнать `score.py` и `mix.sh`.
4. Добавить `Composition` в `src/Root.tsx` и скрипт рендера в `package.json`.

Идеи для следующих серий: «Серия 2: кто за дверью» (горничная / сосед / полиция),
«Серия 3: правило 10 000» (банковские отчёты о наличных), «Серия 4: дорогие
покупки» (почему нельзя просто купить машину), «Серия 5: сообщник», «Серия 6: телефон».
