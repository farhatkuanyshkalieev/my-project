# ГРЯЗНЫЕ МИЛЛИОНЫ — мини-сериал для Reels

Вертикальный мини-сериал 1080×1920, 60 fps, по 60 секунд на серию.
Каждая серия собирается кодом: персонаж, фоны, инфографика и вся моушн-графика
нарисованы в SVG/React (Remotion), музыка и звуки синтезируются скриптом,
озвучка — живой мужской голос из ElevenLabs (голос Fuad, модель eleven_v4,
эмоции задаются тегами: шёпот, смешок, напряжение, паузы).

Сюжет: герой только что украл 10 миллионов наличными. Каждая серия разбирает
одну причину, почему такие деньги становятся ловушкой и как человека в итоге
находят. Формат: «проблема → инфографика → последствие → клиффхэнгер».

## Как устроен проект

```
series/
  src/episodes/ep01/cues.json   ← единый таймлайн (генерируется scripts/build_cues.py)
  src/episodes/ep01/Ep01.tsx    ← сборка серии
  src/episodes/ep01/scenes/     ← сцены серии
  src/components/               ← персонаж, реквизит, HUD, субтитры, переходы, эффекты
  audio/score.py                ← музыка и звуки по cues.json
  audio/mix.sh                  ← сведение: голос + музыка с дакингом + звуки, −14 LUFS
  public/ep01/vo.mp3            ← озвучка (ElevenLabs, голос Fuad, модель eleven_v4)
  public/ep01/words.json        ← тайминги слов для субтитров
```

`cues.json` строится из таймингов слов: каждый бит привязан к слову озвучки
(`scripts/build_cues.py`). Его читают и видео, и аудио-скрипт, поэтому при новой
озвучке достаточно пересобрать cues — удары, штампы и звуки встанут сами.

## Сборка

```bash
cd series
npm install
python3 scripts/build_cues.py public/ep01/words.json src/episodes/ep01/cues.json  # таймлайн
python3 audio/score.py src/episodes/ep01/cues.json public/ep01   # музыка + звуки
audio/mix.sh public/ep01 0.15                                    # финальный микс
npm run render:ep1                                               # → out/ep01.mp4

# серия 2 (озвучка начинается на 1.6 с, после трёх ударов)
python3 scripts/build_cues_ep02.py public/ep02/words.json src/episodes/ep02/cues.json
python3 audio/score_ep02.py src/episodes/ep02/cues.json public/ep02
audio/mix.sh public/ep02 1.6
npm run render:ep2                                               # → out/ep02.mp4

# серия 3 (паузы вставлены в озвучку scripts/splice_vo.py, голос начинается на 1.0 с)
python3 scripts/build_cues_ep03.py public/ep03/words.json src/episodes/ep03/cues.json
python3 audio/score_ep03.py src/episodes/ep03/cues.json public/ep03
audio/mix.sh public/ep03 1.0
npm run render:ep3                                               # → out/ep03.mp4
```

Обложка рилса: `npx remotion still src/index.ts Cover1 covers/ep01_cover.png` (компонент `src/covers/Cover.tsx`,
всё важное держится в центральной зоне 3:4 — её показывает сетка профиля).

Баннер YouTube: `npx remotion still src/index.ts YoutubeBanner covers/youtube_banner.png` (2560×1440, аватарка берётся
из `public/brand/avatar.jpg` — в git её нет; безопасная зона 1546×423 по центру).

Быстрые кадры для проверки: `node scripts/stills.mjs out/qa 5.2 22.6 49.0` (для серии 2 — с `COMP=Ep2`), затем
`python3 scripts/sheet.py out/qa out/sheet.jpg`.

В облачной среде Remotion использует предустановленный Chromium
(`remotion.config.ts`), потому что скачать свой браузер ему не даёт сеть.

## Следующая серия

1. Скопировать `src/episodes/ep01` в `ep02`, переписать `cues.json` и сцены.
2. Сгенерировать озвучку тем же голосом (Fuad, `eleven_v4`, с тегами эмоций),
   получить тайминги слов (ElevenLabs Speech-to-Text) и положить в `public/ep02/`.
3. Описать якорные слова в копии `build_cues.py`, собрать cues, прогнать `score.py` и `mix.sh`.
4. Добавить `Composition` в `src/Root.tsx` и скрипт рендера в `package.json`.

Идеи для следующих серий: «Серия 4: делиться или отказать» (по итогам комментариев),
«Серия 5: сообщник», «Серия 6: телефон».
