# Project notes

## Videos: required end card

Every finished video made in this project (ads, Reels, demos, any format) must
end with the end card **"made by @frht.work"**.

- Add it as the last step, after voiceover and music:
  `python3 tools/add_outro.py IN.mp4 OUT.mp4` (2-second black card, rendered
  at the input's resolution and frame rate).
- Deliver only the version with the end card.
