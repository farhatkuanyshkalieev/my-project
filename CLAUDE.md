# Project notes for Claude

This repo is for making motion-design videos (showreels). Before any request to make, rework or extend a video, read **`MOTION_VIDEO_GUIDE.md`** and follow it. It records the approved style, the voice, the film-score approach, the build pipeline, the quality-check rules and the history of the user's feedback. The current reference is v3 (`showreel/reel3.js`, `showreel/score3.py`).

Talk to the user in Russian.

**Credit (always).** Every video must show the credit `made by @f4rh4t._` (the user's handle), small and legible on the final frame, held until the end. If the brand founder is also credited, use a different word for them (e.g. "designed by @…") so the two credits do not clash.
